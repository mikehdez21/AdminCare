# Acceptance

- [ ] `/login` renders after navigation, reload, session error and logout.
- [ ] Logout succeeds and returns to login without a blank screen.
- [ ] Logout failure shows a controlled alert and does not corrupt auth state.
- [ ] The reported `removeChild` error is not caused by the app's root/router transition.
- [ ] No development server is started by agents.
- [ ] Lint/build/type checks pass.

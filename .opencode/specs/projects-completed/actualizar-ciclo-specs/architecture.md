# Architecture

Este trabajo afecta únicamente documentación de operación de agentes y la
organización física de especificaciones bajo `.opencode/specs/`. No modifica la
arquitectura Laravel, React, la base de datos ni contratos API.

Los archivos de política son `AGENTS.md` y
`.opencode/agents/orchestrator.md`. El contenido de cada especificación se
conserva sin cambios al mover su carpeta completa desde `active-projects` a
`projects-completed`.
